# ArchVR
An End-to-End Pipeline for Text-to-3D Floor Plan Generation via Foundational Models and Procedural Vectorization

## team23

## Abstract:
The approach, traditionally, for designing a home involves a lot of communication among the client and the architect. Creating house blueprints is usually a long process because the architect needs to perform multiple revisions of the same blueprint design to ensure the client is happy. The architect has to make these multiple revisions because client’s struggle to visualize their house designs from flat drawings alone. In our project, we aim to build an app that clients can use to help visualize their homes better. We use Generative AI and Large Language Models to generate house floor plans and blueprints based on the input that the client gives. The input can be through voice or text and a client can specify their needs for a house which will then be displayed as a 3D model that the client can use to visualize their house floorplans better. This project hence provides an end-to-end pipeline of the complete architectural design process that clients need to build their home.
